# Nybrogård Kollegiet Website Redesign

Dette repository indeholder en HTML, CSS, JavaScript og Bootstrap-prototype til et redesign af Nybrogård Kollegiets hjemmeside.

Projektet er udarbejdet som afsluttende eksamensprojekt på multimediedesigneruddannelsen med fokus på informationsarkitektur, brugeroplevelse, responsivt design og lettere adgang til vigtig information for beboere og kommende ansøgere.

## Teknologier

- HTML
- CSS
- Bootstrap 5
- Bootstrap Icons
- JavaScript
- GitHub Pages

## Sider

- Forside
- Om kollegiet
- Bolig & ansøgning
- For beboere
- Fællesskab
- Kontakt & hjælp
